System 1 for AI agents

Fast memory and decisions your agent can trust, and audit.

MahaBodi grows an agent a mind like a Bodhi tree. fastmemory graph memory forms the roots, Laya's typed decision models are the leaves, and one Rust engine joins them. It answers in milliseconds, and it says when it doesn't know.

One tree, four parts

Each part of the tree is a component you can test on its own, and every result below traces back to one of them.

Roots

fastmemory graph

Documents become a topology of actions, data and concepts. A density check keeps every record reachable, and hybrid keyword-plus-meaning search finds it again, even through typos.

Trunk

The MahaBodi engine

One Rust core: a query cascade with handoff flags, tournament shortlisting for many options, experience memory, and a script guard.

Branches

Six languages

The same engine and the same JSON API from Rust, Python, Node.js, Java, C#/.NET and Go, all tested against the real model.

Leaves

Laya decisions

Typed choice, score and yes/no answers with calibrated probabilities, in one forward pass. Nothing is generated, so nothing needs parsing.

Measured, not promised

Same machine, same Laya checkpoint on both sides, seeded test samples, and an exact McNemar test on the same items. A result counts as a win only at p < 0.05.

What it does, and what it doesn't

We report ties and losses next to wins. Here is where MahaBodi stands today.

Strong at

  • Decisions with many options (tens to hundreds of labels)
  • Learning from labelled examples instantly, with no retraining
  • Grounding decisions in your own documents, with citations
  • Typo-tolerant memory search
  • Handing off to System 2 when it isn't sure

Not yet

  • It is not a new model; on six suites it matches Laya exactly
  • Retrieval can still be confidently wrong on hard, misspelled queries
  • Memory is in process today; the TB–PB PostgreSQL design is a tested blueprint (Enterprise)
  • Tested on macOS x86_64; no prebuilt packages yet
